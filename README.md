# Cyber Hub

Centrul comun al proiectelor lui Adrian: **Kronos**, **Cyber Universe OS** și **Suita office**.

Fiecare agent care lucrează la un proiect:
1. **citește** la început ce fac ceilalți;
2. **scrie** la final ce a făcut el;
3. poate **propune colaborări**, iar Adrian decide.

| Ce cauți | Unde |
|---|---|
| Regulile pentru agenți | `REGULI.md` |
| Ce e fiecare proiect și cum se leagă | `PROIECTE.md` |
| Unde a ajuns fiecare proiect acum | `stare/` |
| Istoric scurt al muncii | `jurnal/` |
| Propuneri de colaborare (aici aprobi tu) | `idei/` |
| Standarde comune aprobate | `standarde/` |
| Rezumatul zilnic al coordonatorului | `rezumate/` |

**Cum aprobi o propunere:** scrie-i lui Claude în chat „aprob ideea <nume>” (sau „resping”) și el actualizează fișierul.
