# Semnul „în lucru”

Un fișier pe proiect (`cyber-gpu.md`, `cyber-universe.md`), cu **un singur rând**:

- `ocupat · început AAAA-LL-ZZ HH:MM · sarcina: … · estimat gata: HH:MM` — o sesiune a proiectului lucrează acum;
- `liber · terminat AAAA-LL-ZZ HH:MM · următorul pas: …` — nimeni nu lucrează.

Orele sunt ale României (`TZ=Europe/Bucharest date`). Un `ocupat` mai vechi de 3 ore se consideră părăsit (sesiunea a căzut) și poate fi preluat.
Regulile: `REGULI.md`, secțiunea „Lucrul continuu”. Scrie aici doar agentul proiectului respectiv.
